Narmi is a digital banking platform for community banks and credit unions in the United States. The Narmi One platform unifies consumer and business digital banking, omnichannel account opening (Narmi Grow), instant payments over FedNow (Narmi Now), fraud prevention (Narmi Guard), lending (Narmi Lend), a digital back-office (Narmi Command), an API-driven open architecture (Narmi Open), and agentic AI capabilities (Narmi AI). Narmi integrates with major core banking systems including Corelation Keystone, Symitar, Jack Henry Silverlake, Fiserv DNA/Premier, FIS Horizon/IBS, and COCC. The Narmi Public API is a REST API (OAuth 2.0, 189 operations) exposing accounts, balances, transactions, cards, ACH, Fedwire, FedNow, SWIFT wires, deposits, alerts, and messaging. Narmi launched the first MCP server deployed by a U.S. bank (with Grasshopper Bank, August 2025).
